# Licence texts

Reference copies of the licences the templates in this library are published under, one file per key used in the templates' `license` field. Each template's own licence is the one recorded in its front-matter and credited in [ATTRIBUTION.md](../ATTRIBUTION.md); these copies are here so that a licence which asks for its text to accompany the work (Apache 2.0, for example) travels with it.
