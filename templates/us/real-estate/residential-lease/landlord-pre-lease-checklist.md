# Landlord pre-lease checklist

From listing to move-in — the steps before a lease is signed.

## Screen
- [ ] Collect a completed [rental application](../templates/rental-application.md).
- [ ] Verify income and employment.
- [ ] Contact current and prior landlords.
- [ ] Run credit/background checks **only with written consent and in compliance with fair-housing and local law**.
- [ ] Apply the same criteria to every applicant (fair housing).

## Prepare the lease
- [ ] Choose the right template ([residential](../templates/residential-lease-agreement.md), [month-to-month](../templates/month-to-month-rental-agreement.md), or [room](../templates/room-rental-agreement.md)).
- [ ] Fill all `[BRACKETED]` fields.
- [ ] Add state-required disclosures ([state notes](../state-notes/state-considerations.md)).
- [ ] Run the [lease signing checklist](lease-signing-checklist.md).

## Sign & move in
- [ ] Send for e-signature ([workflow](../workflows/lease-to-signature.md)).
- [ ] Collect first month's rent + deposit.
- [ ] Document unit condition (move-in inspection + photos).
- [ ] Hand over keys; provide emergency contact and payment instructions.
