# sources/

Original files (docx, pdf, odt) that templates were converted from, kept when the original formatting matters. Mirror the template's path and name, with the original extension:

```
templates/us/employment/executive/executive-employment-agreement--us-ca.md
sources/us/employment/executive/executive-employment-agreement--us-ca.docx
```

Point the template's `source.file` field at the file. The validator checks that it exists. Only keep originals whose licence permits redistribution (see CONTRIBUTING.md).
